Play in your browser

This port needs the game's data files once; they're then stored in your browser (nothing is uploaded anywhere). Drop files anywhere on this panel — the Forever release .zip and the Classic app's .apk both work as-is.

You must own the game — get the official Android or iOS release. Controls: arrow keys + A/S/D, Enter = start. ESC opens the dev menu if enabled.
