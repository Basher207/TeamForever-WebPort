Starting up…

This is the engine only. Like every other build of this decompilation, it needs the game assets from a legally obtained copy of the official release of Sonic 1 or Sonic 2 (the 2013 mobile version) — a file called Data.rsdk.

Buy it on Google Play or the App Store, then extract the assets from your copy using the Android or iOS tutorial.

Nothing is uploaded. The file is read in your browser and kept there, so you only pick it once.

Pick Data.rsdk, or a .zip containing it — no need to unzip first.
